# Olivia Rodrigo — Creative Portfolio

Website portfolio sederhana yang dibuat sebagai tugas praktikum Pemrograman Web. Website ini menggunakan HTML dan CSS dengan konsep **Responsive Web Design (RWD)** sehingga tampilan dapat menyesuaikan berbagai ukuran perangkat.

## Deskripsi

Website ini menampilkan portfolio dengan tema kreatif yang berisi informasi tentang diri, keahlian, proyek, sertifikasi, dan kontak.

## Teknologi yang Digunakan

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Responsive Web Design
* Git & GitHub

## Responsive Design

Website dibuat dengan pendekatan **mobile-first** dan menggunakan breakpoint:

* Mobile: tampilan dasar
* Tablet: `min-width: 768px`
* Desktop: `min-width: 1024px`

CSS Grid digunakan untuk layout kartu, sedangkan Flexbox digunakan untuk layout satu dimensi seperti navigasi dan tombol.

## Cara Menjalankan

1. Download atau clone repository.
2. Buka folder project menggunakan Visual Studio Code.
3. Buka file `index.html`.
4. Jalankan menggunakan Live Server atau buka langsung melalui browser.
